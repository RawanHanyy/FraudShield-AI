# FraudShield AI

An end-to-end machine learning project for intelligent transaction fraud detection.

## Project Objective

FraudShield AI aims to identify potentially fraudulent financial transactions using machine learning while addressing real-world challenges such as class imbalance, false-positive/false-negative trade-offs, model evaluation, and threshold selection.

The system will compare baseline and advanced machine learning models and expose the final fraud-risk model through an API and demonstration interface.
